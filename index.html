Questions

Common questions

Does ProcessEdge detect my bank automatically?

Yes. The app identifies supported bank layouts automatically from the file structure. You can also select the bank manually for full control, which is useful for less common formats.

What file formats are supported?

PDF (including password-protected PDFs), Excel (.xlsx and .xls), and CSV. ProcessEdge handles the native download formats from all major Indian banks.

Is my financial data safe? Does it go to a server?

Your data never leaves your computer. ProcessEdge is a desktop application that processes everything locally. No cloud upload, no external server — complete data privacy.

Does it work with Tally Prime and Tally ERP 9?

Yes, ProcessEdge exports standard Tally XML that imports cleanly into both Tally Prime and Tally ERP 9.

Can I process multiple bank statements at once?

Yes — the batch module lets you upload multiple files with different banks, process them all together, and download or import to Tally in one action.

What is the GSTR-2A module?

A dedicated tool to convert your GSTR-2A purchase register data into a Tally-importable format — keeping your ITC claims and purchase ledgers in sync with the GST portal.
